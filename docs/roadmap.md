# Roadmap Pengembangan

## Phase 0: Fondasi

- Buat repository structure.
- Tentukan stack final.
- Buat database migration awal.
- Tambahkan observability dasar.
- Definisikan schema lowongan, profil, dan aplikasi.

## Phase 1: MVP

- Registrasi dan autentikasi.
- Profil kandidat dan upload CV.
- Lowongan manual melalui URL atau teks.
- Analisis kecocokan.
- Cover letter dan subject email.
- Preview dan approval.
- Pengiriman Gmail atau Outlook.
- Tracking sent dan replied.

## Phase 2: Otomasi Bercermin

- Sinkronisasi lowongan berkala.
- Pemeringkatan lowongan.
- Filter lokasi, kerja jarak jauh, gaji, dan industri.
- Template CV ATS-friendly.
- Scheduler follow-up.
- Retry pengiriman.
- Dashboard statistik.

## Phase 3: Operasi Lanjutan

- Inbox classifier untuk balasan.
- Rekomendasi skill dari lowongan yang sering gagal terpenuhi.
- Browser workflow dengan approval manusia.
- Multi-account dan multi-candidate.
- Export data lamaran.
- Evaluasi kualitas draft.
- Human feedback untuk memperbaiki prompt.

## Batas MVP yang Tidak Termasuk

- Auto-send tanpa approval manusia.
- Pengambilan lowongan dari situs yang melarang akses otomatis.
- Self-learning berdasarkan data rahasia tanpa kontrol.
- Pengirim email masal atau kampanye spam.
- Menjawab interview atau negosiasi sepenuhnya tanpa review.
